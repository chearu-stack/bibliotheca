# Bibliotheca — Digital Literary Archive

**Bibliotheca** is a status-driven, academic-style digital library showcasing prose and poetry cycles.

## Aesthetics — Design System

- **Theme:** Deep dark academic library.
- **Palette:** Graphite background (`#121316`), aged brass accents (`#c8a261`), and parchment typography (`#e6e4df`).
- **Typography:** Cormorant Garamond for literary content and headings, paired with Montserrat for metadata and interface navigation.

## Technical Architecture

- **Frontend:** Semantic HTML5, Vanilla JavaScript, Modular CSS.
- **Build System:** Automated static build architecture with distribution generated into `/site`.
- **Signature:** Designed in chearu-stack.

## Repository Structure

```text
/
├── site/                    Compiled static distribution
├── content/                 Source prose and poetry assets
├── data/                    Metadata and catalogue registries
├── scripts/                 Static site generation tools
└── css/                     Core design system tokens
```
